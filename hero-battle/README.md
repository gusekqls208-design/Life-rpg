# 영웅대전 · Heroes Arena

아이패드 가로 화면을 우선으로 만든 턴제 전투 프로토타입입니다.

## 실행
GitHub Pages가 저장소 루트의 `main` 브랜치를 배포하도록 설정되어 있다면:
`/hero-battle/` 경로에서 실행할 수 있습니다.

## 현재 포함된 기능
- 11명 영웅 데이터와 영웅별 SVG 스타일 캐릭터 아트
- 최대 3명 파티 편성 및 전투 중 교체
- 기본 공격, 액티브 2종, 궁극기
- 스킬 설명이 포함된 전투 버튼
- 속성 상성, 체력, 방어막, 궁극기 게이지
- 일부 영웅 고유 자원(탄환, 조준, 책략, 연계, 전술 장비)
- 상태이상 표시 및 테스트 효과
- 적 선택, 간단한 적 AI, 회복 물약, 승패 처리
- 아이패드 가로 화면 및 작은 화면 대응

## 참고
현재는 첫 번째 플레이 가능한 프로토타입입니다. 수치, 상태이상 세부 규칙, AI, 애니메이션은 전투 테스트를 거쳐 조정합니다.
